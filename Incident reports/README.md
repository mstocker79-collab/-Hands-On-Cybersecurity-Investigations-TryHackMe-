# Hands-On Cybersecurity Investigations (TryHackMe)

This repository contains structured SOC-style investigations completed through TryHackMe. Each folder represents a full incident investigation with evidence, analysis, and conclusions.

---

## 📁 What’s Inside
- **Investigation Reports** — Step-by-step triage, log review, and findings  
- **Evidence Artifacts** — Screenshots, logs, extracted indicators  
- **MITRE ATT&CK Mapping** — Techniques identified during analysis  
- **Summary Sections** — Clear conclusions for recruiters and hiring managers  

---

## 🎯 Skills Demonstrated
- Windows event log analysis  
- Suspicious PowerShell execution review  
- Network traffic triage  
- IOC extraction and correlation  
- MITRE ATT&CK technique identification  
- Structured incident reporting  

---

## 🧭 How to Read This Portfolio
1. Open any investigation folder  
2. Start with the `SUMMARY.md` file  
3. Review evidence and notes  
4. See MITRE mappings at the end  

This structure mirrors real SOC workflows and makes your work easy for employers to evaluate.
